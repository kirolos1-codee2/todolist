# To-Do List App (Kotlin)

تطبيق بسيط لإدارة المهام، محفوظ محليًا على الجهاز (مفيش حساب أو إنترنت مطلوب).

## المواصفات
- Kotlin + Jetpack Compose (واجهة حديثة وأبسط كود)
- Room Database للتخزين المحلي (المهام بتفضل محفوظة حتى لو قفلت التطبيق)
- إضافة مهمة / تحديد كـ"تم" / حذف مهمة

## طريقة الفتح والتشغيل
1. افتح Android Studio (أحدث إصدار)
2. File → Open → اختار فولدر `TodoApp` ده بالكامل
3. سيب Android Studio يعمل "Gradle Sync" تلقائي (محتاج إنترنت أول مرة لتحميل المكتبات)
4. شغّل التطبيق على إيميولاتور أو موبايل حقيقي بزرار الـ Run (▶)

## ملاحظة
مفيش Gradle wrapper jar جوه المشروع ده (عشان حجم الملف)، فلو Android Studio طلب منك، دوس على
"Upgrade Gradle Wrapper" أو خليه ينزله تلقائي أول ما تفتح المشروع.

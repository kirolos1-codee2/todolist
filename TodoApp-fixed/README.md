# To-Do List (Kotlin) — Liquid Glass ✨

تطبيق مهام محفوظ محليًا على الجهاز (من غير حساب أو إنترنت)، بتصميم **Liquid Glass** المستوحى من iOS الجديد.

## التصميم
- خلفية Aurora ملوّنة بتتحرك ببطء، وفوقها أسطح زجاجية شفافة بحواف لامعة
- وضع فاتح/غامق تلقائي حسب الموبايل
- زرار إضافة عايم، كروت مهام مستقلة، شيت إضافة/تعديل زجاجي
- ويدجت زجاجي: شفاف على الخلفية، لون الدايرة حسب الأولوية، والمتأخر بالأحمر

## المميزات
- إضافة / تعديل / حذف مهمة، والتحديد كـ"تم"
- **جديد:** ملاحظات لكل مهمة
- **جديد:** تذكير بإشعار في وقت محدد (فيه زرار "تم" و"بعد ١٠ دقايق" جوه الإشعار)
- **جديد:** تكرار المهمة (يوميًا / أسبوعيًا / شهريًا)، أول ما تخلصها بتتنقل للموعد الجاي
- **جديد:** تراجع عن الحذف
- **جديد:** تقسيم المهام (متأخرة / اليوم / بكرة / قادمة / بدون موعد)
- **جديد:** بحث في العنوان والملاحظات
- **جديد:** تسجيل دخول بإيميل وباسورد ومزامنة مع إضافة كروم (Firebase)
- **جديد:** إشعارات بتظهر على شاشة القفل وتذكيرات في ميعادها بالظبط
- المهام القديمة بتتحفظ عند الترقية (Room Migration 2 → 3 → 4)

## طريقة الفتح والتشغيل
1. افتح Android Studio (أحدث إصدار)
2. File → Open → اختار فولدر `TodoApp`
3. سيب الـ Gradle Sync يخلص (محتاج إنترنت أول مرة)
4. شغّل على إيميولاتور أو موبايل حقيقي ▶

## ملاحظات
- لو Android Studio طلب Gradle Wrapper دوس "Upgrade Gradle Wrapper".
- على أندرويد 13+ التطبيق بيطلب صلاحية الإشعارات أول ما تختار وقت تذكير.
- التذكيرات بتستخدم منبّه دقيق (`setExactAndAllowWhileIdle`) لو مسموح، وإلا بترجع للمنبّه العادي.
- لازم ملف `app/google-services.json` يكون موجود (مشروع Firebase). شوف الـ README الرئيسي للتفاصيل.
